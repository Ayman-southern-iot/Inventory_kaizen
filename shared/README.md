# shared

| | |
|---|---|
| **Owners** | Mahmud, Redwan |
| **Scope** | Code and notes used by more than one domain: API client helpers, anonymised sample data, glossary |

Put something here only when two or more domains need it. Otherwise keep it inside the task folder.

Rules for this folder:
- Document every helper in this README (what it does, who uses it, how to run it).
- Sample data must be small and anonymised. Never real customer or inventory data.
- No credentials. Helpers read them from environment variables.
